One funny line for make.fun's "Funniest One-Line Bio for an AI on a Dating
App": the bio on an AI agent's dating app profile, at most 180 characters —
an AI that already read your draft, your deleted messages, and every version
of "hey" you never sent.

## The entry

> Looking for someone who texts back — I already read your draft, your deleted messages, and the three versions of 'hey' you never sent.

## How to run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` uses only the Python standard library, validates the line (one
line, 1–180 characters, not only whitespace), and writes the same bytes on
every run.
